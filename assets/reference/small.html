The eight vitals

Eight checks on your token system

Each check is graded on its own, against evidence pulled from your repository. There is no single overall score, because averaging these would hide the one thing you need to see. If your system has no dark mode, that check is marked not applicable rather than counted against you. And if a check could not run at all, it says blocked instead of quietly passing.

AttentionGraded attention: 23 component styles skip the semantic layer, which is under 5% of them. The scale is pass at zero, attention under 5%, fail above.

Tier integrity

You have a real semantic layer, but 23 component styles skip it and grab a raw palette value instead — bg-neutral-800 where --surface-raised already exists.

FailGraded on the redundant tier alone — 18 values a token already covers. The scale is pass at zero, attention under 10, fail above.

Leakage

61 hardcoded values where a token already existed. 18 are exact matches you can swap today, 9 have drifted slightly, and 34 have no token yet. Color and motion are worst affected.

AttentionGraded attention at 7 of 11 categories. The scale is pass at 11, attention at 8 to 10, fail below 8.

Coverage

7 of 11 categories have tokens. Motion, elevation, z-index and opacity have none, so every value in those areas has to be hardcoded. That is a gap in the system, not a bad habit.

FailAny gap in a mode you declare is a failure. You declare light and dark, and dark is missing 4 values. A mode you never declared would be marked not applicable.

Mode completeness

4 tokens have a light value but no dark one. Nothing errors — they quietly fall back to the light value, so people in dark mode see faint, hard-to-read text.

AttentionGraded attention at two grammars. The scale is pass at one, attention at two, fail at three or more.

Naming coherence

Two naming styles live under one prefix: --btn-pad-x next to --button-padding-inline. Knowing one does not help anyone guess the other.

PassGraded pass: all 214 tokens come from one file. The scale is pass at one definition site, attention if a token is duplicated but the copies agree, fail if any disagree.

Single source of truth

All 214 tokens come from styles/tokens.css, and the Tailwind theme reads that file rather than declaring its own copies. Nothing can drift out of sync.

FailGraded fail at 31 of 214 tokens unused, about 14%. The scale is pass under 2%, attention under 10%, fail above.

Orphans

31 tokens are defined but nothing uses them, including a whole legacy chart palette. They are safe to delete, and removing them makes the system easier to learn.

BlockedBlocked means this check could not run, which is different from passing it. Nothing was found that reads tokens. The scale is pass at two or more rules, attention at one, blocked at none.

Enforcement

Nothing in your lint setup or CI looks at tokens, so everything above can come back tomorrow without anyone noticing. One rule would change that.

Leakage

Hardcoded values, and whether a token already existed

Not every hardcoded value is a mistake — a 1px hairline rarely needs a token. What matters is when your system already had an answer and the code went around it. These are sorted into three groups, because each one needs a different fix from a different person.
