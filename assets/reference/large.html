The eight vitals

The same eight checks, at 840 tokens

These eight checks stay the same whether your system holds 20 tokens or 8,000. Only the evidence underneath them changes shape as things get bigger, which is what the rest of this page is about.

Pass

Tier integrity

All three tiers are intact. Every one of your 148 component tokens resolves through a semantic alias, so nothing reaches straight for a raw palette value.

Fail

Leakage

1,645 hardcoded values where a token already existed. The encouraging part is how concentrated it is: the top 12 account for 61 % of every occurrence.

Pass

Coverage

All 11 categories have tokens, including motion, elevation and z-index. The four categories teams most often skip are all covered here.

Fail

Mode completeness

You declare a high-contrast mode but only 11 % of it is filled in. 744 tokens fall back to their light value in a mode that promises something different.

Attention

Naming coherence

One naming pattern holds across 638 tokens. The 202 tokens in legacy.* came before it and were never migrated.

Fail

Single source of truth

Style Dictionary is your source of truth, but 9 tokens are declared again in tailwind.config.ts — and two of those nine now disagree with it.

Fail

Orphans

274 tokens are not referenced anywhere on the web surface: 202 legacy and 72 current. That is a third of the system doing nothing.

Pass

Enforcement

Three rules run in CI: no raw hex, no off-scale spacing, and a check that every new token is defined in all the modes you declare.
