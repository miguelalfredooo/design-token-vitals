The eight vitals

Eight checks on your token system

Each check is graded on its own, against evidence pulled from your repository. There is no single overall score, because averaging these would hide the one thing you need to see. If your system has no dark mode, that check is marked not applicable rather than counted against you. And if a check could not run at all, it says blocked instead of quietly passing.

Pass

Tier integrity

All three tiers are intact. Every one of your 148 component tokens resolves through a semantic alias, so nothing reaches straight for a raw palette value.

Fail

Leakage

1,645 hardcoded values where a token already existed. The encouraging part is how concentrated it is: the top 12 account for 61 % of every occurrence.

Pass

Coverage

All 11 categories have tokens, including motion, elevation and z-index. The four categories teams most often skip are all covered here.

Fail

Mode completeness

You declare a high-contrast mode but only 11 % of it is filled in. 744 tokens fall back to their light value in a mode that promises something different.

Attention

Naming coherence

One naming pattern holds across 638 tokens. The 202 tokens in legacy.* came before it and were never migrated.

Fail

Single source of truth

Style Dictionary is your source of truth, but 9 tokens are declared again in tailwind.config.ts — and two of those nine now disagree with it.

Fail

Orphans

274 tokens are not referenced anywhere on the web surface: 202 legacy and 72 current. That is a third of the system doing nothing.

Pass

Enforcement

Three rules run in CI: no raw hex, no off-scale spacing, and a check that every new token is defined in all the modes you declare.

Leakage

Hardcoded values, and whether a token already existed

Not every hardcoded value is a mistake — a 1px hairline rarely needs a token. What matters is when your system already had an answer and the code went around it. These are sorted into three groups, because each one needs a different fix from a different person.

Mode completeness

Orphans & enforcement

Tokens nothing uses, and what stops this coming back

Orphaned tokens make your system look bigger and more capable than it really is. They stick around because nothing breaks when they go, so nobody ever gets a reason to remove them.

What is protecting this today

1 rule · 0 CI gates
